# Student Score Data Analysis

This mini project demonstrates the basics of data analysis with Pandas, NumPy, and Matplotlib.

## What it does

- Loads a sample student-score dataset from `student_scores.csv`
- Finds and fills a missing score with that subject's average score
- Adds a letter-grade column
- Calculates overall and subject-level averages
- Creates three charts in the `charts` folder:
  - Bar chart: average score by subject
  - Line chart: each student's scores across subjects
  - Pie chart: grade distribution

## Run it

Install the required libraries once:

```bash
pip install -r requirements.txt
```

Then run:

```bash
python analyze_student_scores.py
```
